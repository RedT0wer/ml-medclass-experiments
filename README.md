# ML MedClass Experiments (Pancreatitis Classification Models)

Научно-исследовательский и учебный репозиторий для проведения экспериментов по машинному обучению, подбору гиперпараметров, валидации табличных классификаторов и экспорту моделей в формат ONNX (opset 22) для последующего мобильного инференса при прогнозировании форм острого панкреатита (МКБ-10: K85).

---

## Назначение репозитория

* Сравнительный анализ эффективности алгоритмов классификации: CatBoost, XGBoost, LightGBM, Random Forest, Logistic Regression.
* Препроцессинг биохимических и клинических признаков, расчёт статистик нормализации (Z-score mean/scale) и физиологических диапазонов отсечения `[min, max]`.
* Формирование динамического манифеста метаданных `model_manifest.json` и вычисление контрольных сумм весов SHA-256 (`generate_mobile_manifest.py`).
* Экспорт обученных пайплайнов в сериализованные графы `.onnx` и артефакты `.joblib` для интеграции в клиентское приложение.

